# Vinheria Agnello - Trabalho de Front-End

Site acadêmico do primeiro semestre de Engenharia de Software da FIAP, sobre o caso fictício da Vinheria Agnello.

## Integrante
- Rafael Zuccon

## Páginas
- `index.html`: início.
- `src/pages/sobre.html`: história da vinheria.
- `src/pages/vinhos.html`: catálogo de exemplos de vinhos.
- `src/pages/harmonizacao.html`: dicas, tabela e vídeo.
- `src/pages/contato.html`: formulário demonstrativo.

## Tecnologias
HTML, CSS com Flexbox e JavaScript básico. As cinco páginas contêm meta tags, menu de navegação e imagens ilustrativas. Também são usados lista, tabela, formulário, vídeo, pseudoclasses, pseudoelementos, transições, transformações e animação simples. Os efeitos estão em `src/css/efeitos.css`.

## Como abrir
Abra `index.html` em um navegador. Não é necessário instalar bibliotecas.
